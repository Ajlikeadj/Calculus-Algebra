§ 1

Review of Continuity & Differentiability

Before studying differential equations, we review the foundational concepts of limits, continuity, and differentiability which underpin all subsequent theory.

1.1 Limits and the ε–δ Definition

Formal (ε–δ) Definition of a Limit

We say $\displaystyle\lim_{x \to a} f(x) = L$ if and only if:

$$\forall\,\varepsilon > 0,\;\exists\,\delta > 0 \text{ such that } 0 < |x - a| < \delta \implies |f(x) - L| < \varepsilon$$

Intuitively: we can make $f(x)$ as close to $L$ as desired by taking $x$ sufficiently close to $a$ (but not equal to $a$).

Key Limit Laws

LawStatement
Sum$\lim(f \pm g) = \lim f \pm \lim g$
Product$\lim(f \cdot g) = \lim f \cdot \lim g$
Quotient$\displaystyle\lim\frac{f}{g} = \frac{\lim f}{\lim g}$, provided $\lim g \neq 0$
SqueezeIf $g(x)\le f(x)\le h(x)$ near $a$ and $\lim g=\lim h=L$, then $\lim f=L$
CompositionIf $f$ is continuous at $\lim g(x)=b$, then $\lim f(g(x))=f(b)$

1.2 Continuity

Continuity at a Point

A function $f$ is continuous at $x = a$ if all three conditions hold:

  1. $f(a)$ is defined (exists in the domain)
  2. $\displaystyle\lim_{x\to a} f(x)$ exists (finite)
  3. $\displaystyle\lim_{x\to a} f(x) = f(a)$ (the limit equals the function value)

$f$ is continuous on an interval $[a,b]$ if it is continuous at every interior point and has one-sided continuity at the endpoints.

Types of Discontinuities

TypeConditionExample
Removable $\lim_{x\to a}f(x)$ exists but $\neq f(a)$ or $f(a)$ undefined $f(x)=\frac{\sin x}{x}$ at $x=0$
Jump Left and right limits exist but are not equal: $f(a^-)\neq f(a^+)$ Heaviside step function
Infinite (Essential) $\lim_{x\to a}|f(x)|=\infty$ $f(x)=\frac{1}{x}$ at $x=0$
Oscillatory Limit does not exist due to oscillation $\sin(1/x)$ at $x=0$
Intermediate Value Theorem (IVT)

If $f$ is continuous on $[a,b]$ and $N$ is any value between $f(a)$ and $f(b)$, then there exists $c\in(a,b)$ such that $f(c)=N$. In particular, if $f(a)$ and $f(b)$ have opposite signs, $f$ has at least one root in $(a,b)$.

1.3 Differentiability

Derivative — First Principles $$f'(x) = \lim_{h\to 0}\frac{f(x+h)-f(x)}{h}$$

The function $f$ is differentiable at $x=a$ if this limit exists and is finite. Geometrically, $f'(a)$ is the slope of the tangent line to $y=f(x)$ at $x=a$.

Differentiability ⟹ Continuity

If $f$ is differentiable at $x=a$, then $f$ is continuous at $x=a$. The converse is false — the absolute value function $|x|$ is continuous at $0$ but not differentiable there (corner point).

1.4 Rolle's Theorem

Rolle's Theorem

If $f$ is:

  • Continuous on $[a,b]$
  • Differentiable on $(a,b)$
  • $f(a) = f(b)$

Then there exists at least one $c\in(a,b)$ such that $f'(c) = 0$.

Rolle's Theorem — Example

Verify Rolle's theorem for $f(x)=x^2-4x+3$ on $[1,3]$.

  1. $f(1)=1-4+3=0$, $f(3)=9-12+3=0$ — equal ✓
  2. $f$ is a polynomial — continuous and differentiable everywhere ✓
  3. $f'(x)=2x-4=0 \Rightarrow x=2\in(1,3)$ ✓

So $c=2$ is the guaranteed point where $f'(c)=0$.

1.5 Mean Value Theorem (MVT / LMVT)

Lagrange's Mean Value Theorem (LMVT)

If $f$ is continuous on $[a,b]$ and differentiable on $(a,b)$, then there exists $c\in(a,b)$ such that:

$$f'(c) = \frac{f(b)-f(a)}{b-a}$$

Geometrically: there is a point where the tangent is parallel to the secant line joining $(a,f(a))$ and $(b,f(b))$.

LMVT — Example

Apply LMVT to $f(x)=x^3-x$ on $[0,2]$.

  1. $f(0)=0$, $f(2)=8-2=6$; slope of secant $=\frac{6-0}{2-0}=3$
  2. $f'(x)=3x^2-1$; set $3x^2-1=3 \Rightarrow x^2=\frac{4}{3} \Rightarrow x=\frac{2}{\sqrt{3}}\approx1.155$
  3. $c=\frac{2}{\sqrt{3}}\in(0,2)$ ✓

1.6 L'Hôpital's Rule

L'Hôpital's Rule

If $\displaystyle\lim_{x\to a}\frac{f(x)}{g(x)}$ yields the indeterminate form $\frac{0}{0}$ or $\frac{\infty}{\infty}$, and $f,g$ are differentiable near $a$, and $g'(x)\neq0$ near $a$, then:

$$\lim_{x\to a}\frac{f(x)}{g(x)} = \lim_{x\to a}\frac{f'(x)}{g'(x)}$$

(provided the right-hand limit exists). The rule may be applied repeatedly.

L'Hôpital Examples

Example 1: $\displaystyle\lim_{x\to 0}\frac{\sin x}{x}$ → form $\frac{0}{0}$

$$\lim_{x\to 0}\frac{\cos x}{1} = 1$$

Example 2: $\displaystyle\lim_{x\to\infty}\frac{x^2}{e^x}$ → form $\frac{\infty}{\infty}$

$$\lim_{x\to\infty}\frac{2x}{e^x} \xrightarrow{\text{again}} \lim_{x\to\infty}\frac{2}{e^x} = 0$$

Example 3: $\displaystyle\lim_{x\to 0^+}x\ln x$ → form $0\cdot(-\infty)$; rewrite as $\frac{\ln x}{1/x}$:

$$\lim_{x\to0^+}\frac{1/x}{-1/x^2}=\lim_{x\to0^+}(-x)=0$$
§ 2

First-Order Ordinary Differential Equations

2.1 Classification of ODEs

Basic Terminology
  • Order: The order of the highest derivative present. $y'+y=0$ is 1st order; $y''+y=0$ is 2nd order.
  • Degree: The power of the highest-order derivative after clearing fractions and radicals. Only defined if the ODE is polynomial in its derivatives.
  • Linear ODE: Can be written as $a_n(x)y^{(n)}+\cdots+a_1(x)y'+a_0(x)y=f(x)$. Coefficients depend only on $x$, not on $y$ or its derivatives.
  • Nonlinear ODE: Any ODE that cannot be written in the above linear form (e.g., $yy'=x$ or $(y')^2+y=0$).

2.2 Separable Equations

Separable ODE

An ODE is separable if it can be written in the form:

$$\frac{dy}{dx} = g(x)\,h(y) \quad\Longleftrightarrow\quad \frac{dy}{h(y)} = g(x)\,dx$$

Integrating both sides: $\displaystyle\int\frac{dy}{h(y)} = \int g(x)\,dx + C$

Example 1 — Separable ODE

Solve $\dfrac{dy}{dx} = \dfrac{x^2}{1-y^2}$

  1. Separate: $(1-y^2)\,dy = x^2\,dx$
  2. Integrate: $\displaystyle\int(1-y^2)\,dy = \int x^2\,dx$
  3. Result: $y - \dfrac{y^3}{3} = \dfrac{x^3}{3} + C$
  4. General solution: $3y - y^3 = x^3 + C_1$ (implicit form)
Example 2 — Separable ODE with IVP

Solve $\dfrac{dy}{dx} = -2xy$, $y(0)=3$

  1. Separate: $\dfrac{dy}{y} = -2x\,dx$
  2. Integrate: $\ln|y| = -x^2 + C$
  3. Exponentiate: $y = Ae^{-x^2}$ where $A=e^C$
  4. Apply IC: $y(0)=A=3$
  5. Particular solution: $\boxed{y = 3e^{-x^2}}$
Example 3 — Separable ODE

Solve $\dfrac{dy}{dx} = \dfrac{y^2 + 1}{xy}$

  1. Separate: $\dfrac{y\,dy}{y^2+1} = \dfrac{dx}{x}$
  2. Integrate LHS: $\dfrac{1}{2}\ln(y^2+1)$; RHS: $\ln|x|+C$
  3. $\ln(y^2+1) = 2\ln|x|+C_1 = \ln x^2 + C_1$
  4. $y^2+1 = Ax^2$ (where $A=e^{C_1}$)
  5. General solution: $y^2 = Ax^2 - 1$

2.3 Exact Equations

Exact ODE

The equation $M(x,y)\,dx + N(x,y)\,dy = 0$ is exact if there exists a function $F(x,y)$ such that $\dfrac{\partial F}{\partial x}=M$ and $\dfrac{\partial F}{\partial y}=N$, i.e., $dF=0$ and the solution is $F(x,y)=C$.

Test for Exactness

The ODE $M\,dx+N\,dy=0$ is exact if and only if:

$$\frac{\partial M}{\partial y} = \frac{\partial N}{\partial x}$$

To find $F$: integrate $M$ with respect to $x$ to get $F=\int M\,dx+g(y)$; then differentiate with respect to $y$ and compare with $N$ to find $g(y)$.

Exact ODE — Example 1

Solve $(2xy+3)\,dx+(x^2-4y)\,dy=0$

  1. $M=2xy+3$, $N=x^2-4y$. Check: $M_y=2x$, $N_x=2x$ ✓ Exact
  2. $F=\int M\,dx=x^2y+3x+g(y)$
  3. $F_y=x^2+g'(y)=N=x^2-4y \Rightarrow g'(y)=-4y \Rightarrow g(y)=-2y^2$
  4. $F=x^2y+3x-2y^2$
  5. General solution: $\boxed{x^2y+3x-2y^2=C}$
Exact ODE — Example 2

Solve $(e^x\sin y+2x)\,dx+(e^x\cos y)\,dy=0$

  1. $M=e^x\sin y+2x$, $N=e^x\cos y$. $M_y=e^x\cos y=N_x$ ✓
  2. $F=\int(e^x\sin y+2x)\,dx = e^x\sin y+x^2+g(y)$
  3. $F_y=e^x\cos y+g'(y)=e^x\cos y \Rightarrow g'(y)=0 \Rightarrow g=C_0$
  4. Solution: $\boxed{e^x\sin y+x^2=C}$

Integrating Factor

If the equation is not exact, an integrating factor $\mu$ can make it exact.

If $\dfrac{M_y-N_x}{N}=f(x)$ alone: $\mu=e^{\int f(x)\,dx}$

If $\dfrac{N_x-M_y}{M}=g(y)$ alone: $\mu=e^{\int g(y)\,dy}$

Integrating Factor — Example

Solve $(y^2+2xy)\,dx - x^2\,dy=0$

  1. $M=y^2+2xy$, $N=-x^2$. $M_y=2y+2x$, $N_x=-2x$. Not exact.
  2. $\dfrac{M_y-N_x}{N}=\dfrac{2y+2x+2x}{-x^2}=\dfrac{2y+4x}{-x^2}$ — depends on both $x,y$. Try the other: $\dfrac{N_x-M_y}{M}=\dfrac{-2x-2y-2x}{y^2+2xy}=\dfrac{-4x-2y}{y(y+2x)}=\dfrac{-2}{y}$
  3. $\mu=e^{\int(-2/y)\,dy}=e^{-2\ln y}=y^{-2}$
  4. Multiply through by $y^{-2}$: $(1+2x/y)\,dx-(x^2/y^2)\,dy=0$
  5. New $M^*=1+2x/y$, $N^*=-x^2/y^2$. Check: $M^*_y=-2x/y^2=N^*_x$ ✓
  6. $F=\int M^*\,dx=x+x^2/y+g(y)$; $F_y=-x^2/y^2+g'(y)=N^*=-x^2/y^2\Rightarrow g'=0$
  7. Solution: $\boxed{x+\dfrac{x^2}{y}=C}$, i.e., $xy+x^2=Cy$

2.4 Linear First-Order ODE

Standard Form $$\frac{dy}{dx} + P(x)\,y = Q(x)$$

This is a first-order linear ODE in $y$. The solution uses an integrating factor.

Derivation of Solution via Integrating Factor

Multiply both sides by $\mu(x)=e^{\int P\,dx}$:

$$e^{\int P\,dx}\frac{dy}{dx} + P(x)e^{\int P\,dx}y = Q(x)e^{\int P\,dx}$$

The left side is exactly $\dfrac{d}{dx}\!\left[e^{\int P\,dx}\cdot y\right]$ (product rule). So:

$$\frac{d}{dx}\left[\mu y\right] = Q\mu$$

Integrate both sides:

$$\mu y = \int Q\mu\,dx + C$$ $$\boxed{y = \frac{1}{\mu}\left[\int Q\mu\,dx + C\right], \quad \mu=e^{\int P(x)\,dx}}$$
Linear First-Order — Example 1

Solve $\dfrac{dy}{dx}+\dfrac{2y}{x}=x^2$

  1. $P=2/x$, $Q=x^2$. $\mu=e^{\int(2/x)\,dx}=e^{2\ln x}=x^2$
  2. Multiply: $x^2y'+2xy=(x^2y)'=x^4$
  3. Integrate: $x^2y=\dfrac{x^5}{5}+C$
  4. Solution: $\boxed{y=\dfrac{x^3}{5}+\dfrac{C}{x^2}}$
Linear First-Order — Example 2

Solve $\dfrac{dy}{dx}-3y=e^{2x}$

  1. $P=-3$, $\mu=e^{-3x}$
  2. $(e^{-3x}y)'=e^{-3x}\cdot e^{2x}=e^{-x}$
  3. Integrate: $e^{-3x}y = -e^{-x}+C$
  4. Solution: $\boxed{y=-e^{2x}+Ce^{3x}}$

2.5 Bernoulli Equation

Bernoulli ODE $$\frac{dy}{dx}+P(x)y = Q(x)y^n, \quad n\neq 0,1$$

Substitution: $v = y^{1-n}$, so $\dfrac{dv}{dx}=(1-n)y^{-n}\dfrac{dy}{dx}$. Dividing through by $y^n$ converts the Bernoulli equation into a linear ODE in $v$:

$$\frac{dv}{dx}+(1-n)P(x)v=(1-n)Q(x)$$
Bernoulli — Example

Solve $\dfrac{dy}{dx}+\dfrac{y}{x}=x^2y^3$

  1. $n=3$; let $v=y^{-2}$, $v'=-2y^{-3}y'$
  2. Divide original by $y^3$: $y^{-3}y'+\dfrac{y^{-2}}{x}=x^2$
  3. $-\frac{1}{2}v'+\frac{v}{x}=x^2 \Rightarrow v'-\frac{2v}{x}=-2x^2$
  4. $\mu=e^{-2\int dx/x}=x^{-2}$
  5. $(x^{-2}v)'=-2$; integrate: $x^{-2}v=-2x+C$
  6. $v=y^{-2}=-2x^3+Cx^2$
  7. Solution: $\boxed{\dfrac{1}{y^2}=Cx^2-2x^3}$

2.6 Applications of First-Order ODEs

Population Growth / Decay

Exponential Model

If rate of growth is proportional to population: $\dfrac{dP}{dt}=kP$

Separating and integrating: $P(t)=P_0e^{kt}$

For decay (radioactive): $k<0$, giving $P(t)=P_0e^{-\lambda t}$. Half-life: $t_{1/2}=\dfrac{\ln 2}{\lambda}$

Newton's Law of Cooling

Newton's Cooling

Rate of cooling proportional to temperature difference with surroundings:

$$\frac{dT}{dt}=-k(T-T_s), \quad k>0$$

This is linear; solution: $T(t)=T_s+(T_0-T_s)e^{-kt}$

Problem: A body at $100°C$ cools to $60°C$ in $10$ min in a $20°C$ room. Find temperature after $20$ min.

  1. $T(t)=20+(100-20)e^{-kt}=20+80e^{-kt}$
  2. $T(10)=60$: $60=20+80e^{-10k}\Rightarrow e^{-10k}=\frac{1}{2}\Rightarrow k=\frac{\ln2}{10}$
  3. $T(20)=20+80e^{-20k}=20+80\cdot\left(\frac{1}{2}\right)^2=20+20=40°C$

RC Circuit

RC Circuit (Series)

By Kirchhoff's voltage law for a series RC circuit with EMF $E(t)$:

$$R\,\frac{dq}{dt}+\frac{q}{C}=E(t)$$

This is linear in $q(t)$. With $E=E_0$ (constant), the solution is:

$$q(t)=CE_0+\left(q_0-CE_0\right)e^{-t/(RC)}$$

The current is $I(t)=\dfrac{dq}{dt}=\dfrac{E_0-q_0/C}{R}e^{-t/(RC)}$. The time constant is $\tau=RC$.

§ 3

Linear 2nd-Order ODE with Constant Coefficients

Standard Form $$ay''+by'+cy=f(x)$$

where $a,b,c$ are real constants, $a\neq0$. When $f(x)=0$ the equation is homogeneous; otherwise it is non-homogeneous.

The general solution is: $y = y_c + y_p$ where $y_c$ is the complementary function (solution of the homogeneous equation) and $y_p$ is a particular integral.

3.1 Complementary Function (CF)

Assume $y=e^{rx}$ for the homogeneous equation $ay''+by'+cy=0$. Substituting:

$$ar^2e^{rx}+bre^{rx}+ce^{rx}=0 \implies \boxed{ar^2+br+c=0}$$

This is the characteristic (auxiliary) equation. Its discriminant $\Delta=b^2-4ac$ determines the three cases:

Three Cases for the CF
CaseConditionRoots$y_c$
I — Distinct Real $\Delta > 0$ $r_1,r_2\in\mathbb{R}$, $r_1\neq r_2$ $C_1e^{r_1x}+C_2e^{r_2x}$
II — Repeated Real $\Delta = 0$ $r_1=r_2=r=-\dfrac{b}{2a}$ $(C_1+C_2x)e^{rx}$
III — Complex $\Delta < 0$ $r=\alpha\pm i\beta$ $e^{\alpha x}(C_1\cos\beta x+C_2\sin\beta x)$

where $\alpha=-\dfrac{b}{2a}$ and $\beta=\dfrac{\sqrt{4ac-b^2}}{2a}$.

Derivation: Repeated Root Case

When $r_1=r_2=r$, one solution is $y_1=e^{rx}$. We need a second linearly independent solution. Using reduction of order: let $y_2=v(x)e^{rx}$. Then:

$$y_2'=(v'+rv)e^{rx},\quad y_2''=(v''+2rv'+r^2v)e^{rx}$$

Substituting into $ay''+by'+cy=0$ and using $ar^2+br+c=0$ and $2ar+b=0$ (repeated root condition), we get $av''=0$, so $v''=0$, thus $v=C_1+C_2x$. Hence:

$$y_2=(C_1+C_2x)e^{rx}$$

3.2 Particular Integral (PI) — Undetermined Coefficients

For the non-homogeneous part $f(x)$, we guess a form for $y_p$ based on $f(x)$:

$f(x)$ formTrial $y_p$Modification
$x^n$ (polynomial, degree $n$)$A_nx^n+\cdots+A_1x+A_0$—
$e^{\alpha x}$$Ae^{\alpha x}$Multiply by $x^s$ if $\alpha$ is a root of char. eq. ($s=1$ simple, $s=2$ repeated)
$\cos\beta x$ or $\sin\beta x$$A\cos\beta x+B\sin\beta x$Multiply by $x$ if $i\beta$ is a root
$e^{\alpha x}\cos\beta x$$e^{\alpha x}(A\cos\beta x+B\sin\beta x)$Multiply by $x$ if $\alpha+i\beta$ is a root
$x^ne^{\alpha x}$$e^{\alpha x}(A_nx^n+\cdots+A_0)$Multiply by $x^s$ as needed

3.3 Operator Method (D-notation)

D-Operator

Let $D=\dfrac{d}{dx}$, so $D^2y=y''$, etc. The ODE becomes $f(D)y=Q(x)$ where $f(D)=aD^2+bD+c$.

The particular integral is $y_p=\dfrac{1}{f(D)}Q(x)$, evaluated by the following rules:

  • Exponential: $\dfrac{1}{f(D)}e^{ax}=\dfrac{e^{ax}}{f(a)}$, provided $f(a)\neq0$
  • Failure case: If $f(a)=0$, use $\dfrac{1}{f(D)}e^{ax}=x\dfrac{e^{ax}}{f'(a)}$, etc.
  • Trig: Replace $D^2\to-\beta^2$ in $\dfrac{1}{f(D^2)}\sin\beta x$ or $\cos\beta x$
  • Polynomial: Expand $\dfrac{1}{f(D)}$ as a power series in $D$ and operate term by term

3.4 Worked Examples (Full Solutions)

Example 1 — Distinct Real Roots

Solve $y''-5y'+6y=e^{2x}$

  1. CF: Char. eq. $r^2-5r+6=(r-2)(r-3)=0\Rightarrow r=2,3$
  2. $y_c=C_1e^{2x}+C_2e^{3x}$
  3. PI: Since $\alpha=2$ is a root, trial $y_p=Axe^{2x}$
  4. $y_p'=Ae^{2x}(1+2x)$, $y_p''=Ae^{2x}(4+4x)$
  5. Sub: $A(4+4x)e^{2x}-5A(1+2x)e^{2x}+6Axe^{2x}=e^{2x}$
  6. $Ae^{2x}(4+4x-5-10x+6x)=e^{2x}\Rightarrow A(-1)=1\Rightarrow A=-1$
  7. $y_p=-xe^{2x}$
  8. General solution: $\boxed{y=C_1e^{2x}+C_2e^{3x}-xe^{2x}}$
Example 2 — Complex Roots + Trig RHS

Solve $y''+4y=3\sin 2x$

  1. CF: $r^2+4=0\Rightarrow r=\pm2i$; $\alpha=0$, $\beta=2$
  2. $y_c=C_1\cos2x+C_2\sin2x$
  3. PI: Since $\pm2i$ are roots, multiply trial by $x$: $y_p=x(A\cos2x+B\sin2x)$
  4. $y_p'=A\cos2x+B\sin2x+x(-2A\sin2x+2B\cos2x)$
  5. $y_p''=-4A\sin2x+4B\cos2x+(-4Ax\cos2x-4Bx\sin2x)+(-4Ax\cos2x-4Bx\sin2x)$
  6. $y_p''=4B\cos2x-4A\sin2x-4x(A\cos2x+B\sin2x)$
  7. $y_p''+4y_p=4B\cos2x-4A\sin2x=3\sin2x$
  8. $4B=0\Rightarrow B=0$; $-4A=3\Rightarrow A=-\frac{3}{4}$
  9. $y_p=-\frac{3}{4}x\cos2x$
  10. General solution: $\boxed{y=C_1\cos2x+C_2\sin2x-\tfrac{3}{4}x\cos2x}$
Example 3 — Repeated Roots + Polynomial RHS

Solve $y''-4y'+4y=x^2e^{2x}$

  1. CF: $(r-2)^2=0\Rightarrow r=2$ (double root)
  2. $y_c=(C_1+C_2x)e^{2x}$
  3. PI: $\alpha=2$ is a double root, so multiply by $x^2$: $y_p=e^{2x}(Ax^4+Bx^3+Cx^2)/1$
  4. Actually: trial $y_p=x^2e^{2x}(Ax^2+Bx+C)$
  5. Using D-operator: $y_p=\dfrac{e^{2x}x^2}{(D-2)^2}$. Since $(D-2)$ acting on $e^{2x}$ shifts $D\to D+2$: $y_p=e^{2x}\dfrac{x^2}{D^2}=e^{2x}\dfrac{x^4}{12}$
  6. General solution: $\boxed{y=\left(C_1+C_2x+\dfrac{x^4}{12}\right)e^{2x}}$
Example 4 — IVP, Complex Roots

Solve $y''+2y'+5y=0$, $y(0)=1$, $y'(0)=0$

  1. Char. eq.: $r^2+2r+5=0\Rightarrow r=\dfrac{-2\pm\sqrt{4-20}}{2}=-1\pm2i$
  2. $y=e^{-x}(C_1\cos2x+C_2\sin2x)$
  3. $y(0)=C_1=1$
  4. $y'=-e^{-x}(C_1\cos2x+C_2\sin2x)+e^{-x}(-2C_1\sin2x+2C_2\cos2x)$
  5. $y'(0)=-C_1+2C_2=0\Rightarrow C_2=\frac{1}{2}$
  6. Solution: $\boxed{y=e^{-x}\!\left(\cos2x+\tfrac{1}{2}\sin2x\right)}$
Example 5 — $f(x)=xe^x+\cos x$

Find the PI of $y''-3y'+2y=xe^x+\cos x$

  1. Char. roots: $r=1,2$
  2. PI for $xe^x$: $\alpha=1$ is simple root; trial $y_{p1}=xe^x(Ax+B)$
  3. $y_{p1}=e^x(Ax^2+Bx)$; after substitution: $A=-1$, $B=-2$; $y_{p1}=e^x(-x^2-2x)$
  4. PI for $\cos x$: try $y_{p2}=A\cos x+B\sin x$
  5. $y_{p2}''=-A\cos x-B\sin x$; substituting: $(1-A-3B)\cos x+(1B-3A-B)\sin x$ wait let me redo:
  6. $(y_{p2})'=-A\sin x+B\cos x$; $y_{p2}''=-A\cos x-B\sin x$
  7. $-A\cos x-B\sin x-3(-A\sin x+B\cos x)+2(A\cos x+B\sin x)=\cos x$
  8. $(A-3B)\cos x+(3A+B)\sin x=\cos x\Rightarrow A-3B=1$, $3A+B=0\Rightarrow B=-3A$
  9. $A+9A=1\Rightarrow A=\frac{1}{10}$, $B=-\frac{3}{10}$
  10. $y_p=e^x(-x^2-2x)+\frac{1}{10}\cos x-\frac{3}{10}\sin x$
§ 4

Higher-Order Linear ODE with Constant Coefficients

The methods of §3 extend naturally to $n$th-order equations:

$n$th-Order Linear ODE $$a_ny^{(n)}+a_{n-1}y^{(n-1)}+\cdots+a_1y'+a_0y=f(x)$$

Characteristic equation: $a_nr^n+a_{n-1}r^{n-1}+\cdots+a_1r+a_0=0$, which has $n$ roots (counting multiplicity, possibly complex).

Superposition Principle

If $y_1,\ldots,y_n$ are $n$ linearly independent solutions of the homogeneous equation, then the general solution of the homogeneous equation is $y_c=C_1y_1+\cdots+C_ny_n$. The general solution of the non-homogeneous equation is $y=y_c+y_p$.

4th-Order ODE — Complete Example

Solve $y^{(4)}-y=0$

  1. Characteristic equation: $r^4-1=0\Rightarrow(r^2-1)(r^2+1)=0$
  2. Roots: $r=1,-1,i,-i$
  3. CF: $y_c=C_1e^x+C_2e^{-x}+C_3\cos x+C_4\sin x$
  4. This is also $y_c=A\cosh x+B\sinh x+C_3\cos x+C_4\sin x$
  5. General solution: $\boxed{y=C_1e^x+C_2e^{-x}+C_3\cos x+C_4\sin x}$
4th-Order ODE with RHS

Solve $y^{(4)}-2y'''+y''=e^x+x$

  1. Char. eq.: $r^4-2r^3+r^2=r^2(r^2-2r+1)=r^2(r-1)^2=0$
  2. Roots: $r=0$ (double), $r=1$ (double)
  3. $y_c=(C_1+C_2x)+(C_3+C_4x)e^x$
  4. PI for $e^x$: $\alpha=1$ is double root; $y_{p1}=\dfrac{x^2e^x}{f''(1)}$; $f(r)=r^2(r-1)^2$, $f''(1)=2$; $y_{p1}=\dfrac{x^2e^x}{2}$
  5. PI for $x$: $y_{p2}=Ax^3+Bx^2$ (multiply $x$ by $x^2$ for double zero root)
  6. $(y_{p2})''=6Ax+2B$, $(y_{p2})'=3Ax^2+2Bx$, $(y_{p2})'''=6A$, $(y_{p2})^{(4)}=0$
  7. Substituting: $0-2(6A)+6Ax+2B=x\Rightarrow 6Ax+(2B-12A)=x$
  8. $6A=1\Rightarrow A=1/6$; $2B-12A=0\Rightarrow B=1$
  9. $y_{p2}=\dfrac{x^3}{6}+x^2$
  10. General solution: $y=(C_1+C_2x)+(C_3+C_4x)e^x+\dfrac{x^2e^x}{2}+\dfrac{x^3}{6}+x^2$

Key Points — Higher-Order ODEs

  • The number of arbitrary constants in $y_c$ equals the order of the ODE
  • Each distinct real root contributes one exponential term
  • A $k$-fold root contributes $k$ independent solutions (polynomial-times-exponential)
  • Complex roots always come in conjugate pairs for real-coefficient ODEs
  • PI method is the same; superposition applies for sums in $f(x)$
§ 5

Cauchy–Euler Equation

Cauchy–Euler (Equidimensional) Equation $$x^2y''+axy'+by=f(x)$$

or more generally the $n$th-order form: $a_nx^ny^{(n)}+a_{n-1}x^{n-1}y^{(n-1)}+\cdots+a_0y=f(x)$. Note that the coefficient of $y^{(k)}$ is $x^k$ (times a constant). This is also called the equidimensional equation because under the scaling $x\to\lambda x$, the equation has the same form.

5.1 Substitution $x = e^t$ (or $t = \ln x$)

Full Derivation of the Reduction

Let $x=e^t$, so $t=\ln x$ (for $x>0$). Then:

$$\frac{dy}{dx}=\frac{dy}{dt}\cdot\frac{dt}{dx}=\frac{1}{x}\frac{dy}{dt} \implies x\frac{dy}{dx}=\frac{dy}{dt}\equiv Dy \text{ (with }D=d/dt\text{)}$$

For the second derivative:

$$\frac{d^2y}{dx^2}=\frac{d}{dx}\left(\frac{1}{x}\frac{dy}{dt}\right)=-\frac{1}{x^2}\frac{dy}{dt}+\frac{1}{x^2}\frac{d^2y}{dt^2}$$ $$x^2\frac{d^2y}{dx^2}=\frac{d^2y}{dt^2}-\frac{dy}{dt}=(D^2-D)y=D(D-1)y$$

Similarly: $x^3y'''=D(D-1)(D-2)y$, and in general $x^ky^{(k)}=D(D-1)\cdots(D-k+1)y$.

The Cauchy–Euler equation $x^2y''+axy'+by=0$ becomes:

$$D(D-1)y+aDy+by=0 \implies [D^2+(a-1)D+b]y=0$$

This is a linear ODE with constant coefficients in the variable $t$!

Characteristic Equation for Cauchy–Euler $$m(m-1)+am+b=0 \implies m^2+(a-1)m+b=0$$

Equivalently, try $y=x^m$ directly in $x^2y''+axy'+by=0$:

$$m(m-1)x^m+amx^m+bx^m=0 \implies m^2+(a-1)m+b=0$$
Three Cases for Cauchy–Euler CF
CaseRoots $m_1,m_2$$y_c$
Distinct real $m_1\neq m_2$, both real $C_1x^{m_1}+C_2x^{m_2}$
Repeated real $m_1=m_2=m$ $x^m(C_1+C_2\ln x)$
Complex $m=\alpha\pm i\beta$ $x^\alpha[C_1\cos(\beta\ln x)+C_2\sin(\beta\ln x)]$

The complex case follows from $x^{\alpha+i\beta}=x^\alpha e^{i\beta\ln x}=x^\alpha[\cos(\beta\ln x)+i\sin(\beta\ln x)]$.

5.2 Worked Examples

Example 1 — Distinct Real Roots

Solve $x^2y''-2xy'-4y=0$ (for $x>0$)

  1. Try $y=x^m$: $m(m-1)-2m-4=0\Rightarrow m^2-3m-4=0$
  2. $(m-4)(m+1)=0\Rightarrow m=4,-1$
  3. General solution: $\boxed{y=C_1x^4+C_2x^{-1}}$
Example 2 — Repeated Root

Solve $x^2y''-xy'+y=0$

  1. $m(m-1)-m+1=0\Rightarrow m^2-2m+1=0\Rightarrow(m-1)^2=0$
  2. $m=1$ (double root)
  3. General solution: $\boxed{y=x(C_1+C_2\ln x)}$
Example 3 — Complex Roots

Solve $x^2y''+xy'+y=0$

  1. $m(m-1)+m+1=0\Rightarrow m^2+1=0\Rightarrow m=\pm i$
  2. $\alpha=0$, $\beta=1$
  3. General solution: $\boxed{y=C_1\cos(\ln x)+C_2\sin(\ln x)}$

5.3 Non-Homogeneous Cauchy–Euler

For $x^2y''+axy'+by=f(x)$, substitute $x=e^t$ to convert to a constant-coefficient ODE, solve in $t$ (find CF + PI in $t$), then back-substitute $t=\ln x$.

Example 4 — Non-Homogeneous

Solve $x^2y''+2xy'-2y=x^2$

  1. Char. eq.: $m^2+m-2=0\Rightarrow(m+2)(m-1)=0\Rightarrow m=-2,1$
  2. $y_c=C_1x+C_2x^{-2}$
  3. PI: Try $y_p=Ax^2$; $y_p'=2Ax$, $y_p''=2A$
  4. $x^2(2A)+2x(2Ax)-2Ax^2=x^2\Rightarrow2A+4A-2A=1\Rightarrow4A=1\Rightarrow A=\frac{1}{4}$
  5. General solution: $\boxed{y=C_1x+C_2x^{-2}+\dfrac{x^2}{4}}$
Example 5 — Via Substitution

Solve $x^2y''-3xy'+4y=x^2\ln x$

  1. Let $x=e^t$: $[D(D-1)-3D+4]y=e^{2t}\cdot t$, i.e., $(D^2-4D+4)y=te^{2t}$
  2. $(D-2)^2y=te^{2t}$. CF: $y_c=(C_1+C_2t)e^{2t}$
  3. $r=2$ is a double root; PI $=\dfrac{te^{2t}}{(D-2)^2}=e^{2t}\dfrac{t}{D^2}=e^{2t}\cdot\dfrac{t^3}{6}$
  4. Back-substitute $t=\ln x$, $e^t=x$: $y_c=(C_1+C_2\ln x)x^2$
  5. $y_p=x^2\cdot\dfrac{(\ln x)^3}{6}$
  6. General solution: $\boxed{y=x^2\!\left(C_1+C_2\ln x+\dfrac{(\ln x)^3}{6}\right)}$
§ 6

Legendre's Equation & Polynomials

Legendre's Differential Equation $$(1-x^2)y'' - 2xy' + n(n+1)y = 0, \quad x\in[-1,1]$$

where $n$ is a non-negative integer. This equation arises in physics when solving Laplace's equation in spherical coordinates (separation of variables).

Rewritten in self-adjoint (Sturm–Liouville) form:

$$\frac{d}{dx}\left[(1-x^2)\frac{dy}{dx}\right]+n(n+1)y=0$$

6.1 Power Series Solution

Since $x=0$ is an ordinary point, assume $y=\displaystyle\sum_{k=0}^\infty a_k x^k$. Then $y'=\sum ka_kx^{k-1}$ and $y''=\sum k(k-1)a_kx^{k-2}$. Substituting into Legendre's equation and collecting powers of $x^k$:

Recurrence Relation $$a_{k+2} = -\frac{(n-k)(n+k+1)}{(k+1)(k+2)}\,a_k$$

This gives two independent series solutions: one in even powers (from $a_0$) and one in odd powers (from $a_1$). For non-negative integer $n$, one of these series terminates, giving a polynomial — the Legendre polynomial $P_n(x)$.

6.2 Legendre Polynomials

By convention, $P_n(1)=1$. The first several Legendre polynomials are:

$n$$P_n(x)$$P_n(0)$$P_n(1)$$P_n(-1)$
0$1$$1$$1$$1$
1$x$$0$$1$$-1$
2$\frac{1}{2}(3x^2-1)$$-\frac{1}{2}$$1$$1$
3$\frac{1}{2}(5x^3-3x)$$0$$1$$-1$
4$\frac{1}{8}(35x^4-30x^2+3)$$\frac{3}{8}$$1$$1$
5$\frac{1}{8}(63x^5-70x^3+15x)$$0$$1$$-1$

6.3 Rodrigues' Formula

Rodrigues' Formula $$P_n(x)=\frac{1}{2^n n!}\frac{d^n}{dx^n}\left[(x^2-1)^n\right]$$

This provides a closed-form expression for each $P_n$ without using the series or recurrence directly.

Rodrigues' Formula — Deriving $P_2$
  1. $n=2$: $\frac{1}{4\cdot2}\frac{d^2}{dx^2}(x^2-1)^2$
  2. $(x^2-1)^2=x^4-2x^2+1$
  3. First derivative: $4x^3-4x$; second derivative: $12x^2-4$
  4. $P_2=\frac{1}{8}(12x^2-4)=\frac{3x^2-1}{2}$ ✓

6.4 Orthogonality of Legendre Polynomials

Orthogonality Relation $$\int_{-1}^{1}P_m(x)P_n(x)\,dx = \begin{cases} 0 & m\neq n \\ \dfrac{2}{2n+1} & m=n \end{cases}$$

This makes the Legendre polynomials an orthogonal basis for $L^2[-1,1]$. Any function $f(x)$ can be expanded as:

$$f(x)=\sum_{n=0}^\infty c_n P_n(x), \quad c_n=\frac{2n+1}{2}\int_{-1}^1 f(x)P_n(x)\,dx$$

6.5 Recurrence Relations

Key Recurrence Relations

Three-term recurrence (Bonnet's formula):

$$(n+1)P_{n+1}(x)=(2n+1)xP_n(x)-nP_{n-1}(x)$$

Derivative recurrence:

$$P_n'(x)-xP_{n-1}'(x)=nP_{n-1}(x)$$ $$(1-x^2)P_n'(x)=nP_{n-1}(x)-nxP_n(x)$$

Another relation:

$$P_{n+1}'(x)-P_{n-1}'(x)=(2n+1)P_n(x)$$

6.6 Generating Function

Generating Function $$\frac{1}{\sqrt{1-2xt+t^2}}=\sum_{n=0}^\infty P_n(x)\,t^n, \quad |t|<1$$

Expanding the left side in powers of $t$ and equating coefficients yields $P_n(x)$. This generating function is physically important: if $r$ and $r'$ are distances from the origin, and $\theta$ is the angle between them, then the electrostatic potential is $\propto\frac{1}{\sqrt{r^2+r'^2-2rr'\cos\theta}}=\frac{1}{r}\sum P_n(\cos\theta)(r'/r)^n$.

Properties of Legendre Polynomials

  • $P_n(x)$ has exactly $n$ distinct real zeros in $(-1,1)$
  • $P_n(-x)=(-1)^nP_n(x)$ — even/odd symmetry
  • $|P_n(x)|\le1$ for all $x\in[-1,1]$
  • The leading coefficient of $P_n$ is $\frac{(2n)!}{2^n(n!)^2}$
  • $P_n(1)=1$ and $P_n(-1)=(-1)^n$ for all $n$
§ 7

Method of Variation of Parameters

Overview

Variation of parameters is a general method for finding a particular integral of any second-order linear ODE — even when $f(x)$ is not of the special forms required by undetermined coefficients. It works whenever we know the complementary function.

Consider: $y'' + P(x)y' + Q(x)y = R(x)$

Suppose the CF is $y_c = C_1y_1(x) + C_2y_2(x)$. We "vary" the constants by letting $C_1\to u_1(x)$ and $C_2\to u_2(x)$, so $y_p = u_1y_1 + u_2y_2$.

7.1 Wronskian

The Wronskian $$W(y_1,y_2) = \begin{vmatrix}y_1 & y_2\\ y_1' & y_2'\end{vmatrix} = y_1y_2'-y_2y_1'$$

Abel's Identity states that $W(x)=W(x_0)\exp\!\left(-\displaystyle\int_{x_0}^xP(t)\,dt\right)$, so $W\neq0$ whenever $y_1,y_2$ are linearly independent.

7.2 Derivation of the Formulas

Full Derivation

Let $y_p=u_1y_1+u_2y_2$. Then $y_p'=u_1'y_1+u_1y_1'+u_2'y_2+u_2y_2'$. We impose the condition:

$$u_1'y_1+u_2'y_2=0 \quad\text{(Condition 1)}$$

So $y_p'=u_1y_1'+u_2y_2'$ and $y_p''=u_1'y_1'+u_1y_1''+u_2'y_2'+u_2y_2''$. Substituting into $y''+Py'+Qy=R$:

$$u_1(y_1''+Py_1'+Qy_1)+u_2(y_2''+Py_2'+Qy_2)+u_1'y_1'+u_2'y_2'=R$$

Since $y_1,y_2$ satisfy the homogeneous equation, the bracketed terms vanish:

$$u_1'y_1'+u_2'y_2'=R \quad\text{(Condition 2)}$$

Solving the $2\times2$ system (Conditions 1 & 2) by Cramer's rule:

$$u_1'=\frac{-y_2R}{W},\quad u_2'=\frac{y_1R}{W}$$ $$\boxed{u_1=-\int\frac{y_2R}{W}\,dx,\qquad u_2=\int\frac{y_1R}{W}\,dx}$$ $$\boxed{y_p=-y_1\int\frac{y_2R}{W}\,dx+y_2\int\frac{y_1R}{W}\,dx}$$

7.3 Worked Examples

Example 1 — Trig RHS (Classic)

Solve $y''+y=\sec x$ using variation of parameters.

  1. CF: $r^2+1=0\Rightarrow r=\pm i$; $y_c=C_1\cos x+C_2\sin x$
  2. $y_1=\cos x$, $y_2=\sin x$, $R=\sec x$
  3. $W=\cos x\cdot\cos x-\sin x\cdot(-\sin x)=\cos^2x+\sin^2x=1$
  4. $u_1'=-\dfrac{y_2R}{W}=-\sin x\sec x=-\tan x$
  5. $u_1=\int(-\tan x)\,dx=\ln|\cos x|$
  6. $u_2'=\dfrac{y_1R}{W}=\cos x\sec x=1$
  7. $u_2=\int1\,dx=x$
  8. $y_p=\ln|\cos x|\cdot\cos x+x\sin x$
  9. General solution: $\boxed{y=C_1\cos x+C_2\sin x+\cos x\ln|\cos x|+x\sin x}$
Example 2 — Exponential RHS

Solve $y''-3y'+2y=\dfrac{e^x}{1+e^x}$

  1. CF: $(r-1)(r-2)=0$; $y_1=e^x$, $y_2=e^{2x}$
  2. $W=e^x\cdot2e^{2x}-e^{2x}\cdot e^x=e^{3x}$
  3. $R=\dfrac{e^x}{1+e^x}$
  4. $u_1'=-\dfrac{y_2R}{W}=-\dfrac{e^{2x}\cdot e^x/(1+e^x)}{e^{3x}}=-\dfrac{1}{1+e^x}$
  5. $u_1=-\int\dfrac{dx}{1+e^x}$. Substitute $e^x=t$: $\int\dfrac{dt}{t(1+t)}=\ln|t|-\ln|1+t|=\ln\dfrac{e^x}{1+e^x}=x-\ln(1+e^x)$
  6. $u_1=-(x-\ln(1+e^x))=\ln(1+e^x)-x$
  7. $u_2'=\dfrac{y_1R}{W}=\dfrac{e^x\cdot e^x/(1+e^x)}{e^{3x}}=\dfrac{e^{-x}}{1+e^x}=\dfrac{1}{e^x+e^{2x}}$
  8. $u_2=\int\dfrac{e^{-x}}{1+e^x}\,dx$; let $u=e^{-x}$: $-\int\dfrac{du}{1+(1/u)}=-\int\dfrac{u\,du}{u+1}=-u+\ln(u+1)=-e^{-x}+\ln(1+e^{-x})$
  9. $y_p=e^x[\ln(1+e^x)-x]+e^{2x}[-e^{-x}+\ln(1+e^{-x})]$
  10. $=e^x\ln(1+e^x)-xe^x-e^x+e^{2x}\ln(1+e^{-x})$
  11. This can be simplified using $e^{2x}\ln(1+e^{-x})=e^{2x}\ln\!\tfrac{e^x+1}{e^x}=e^{2x}[\ln(1+e^x)-x]$
  12. General solution: $y=C_1e^x+C_2e^{2x}+y_p$
Example 3 — $R(x)=x^{-2}e^x$

Solve $y''-2y'+y=\dfrac{e^x}{x^2}$ by variation of parameters.

  1. CF: $(r-1)^2=0$; $y_1=e^x$, $y_2=xe^x$
  2. $W=e^x(e^x+xe^x)-(xe^x)(e^x)=e^{2x}+xe^{2x}-xe^{2x}=e^{2x}$
  3. $u_1'=-\dfrac{xe^x\cdot e^x/x^2}{e^{2x}}=-\dfrac{1}{x}$
  4. $u_1=-\ln x$
  5. $u_2'=\dfrac{e^x\cdot e^x/x^2}{e^{2x}}=\dfrac{1}{x^2}$
  6. $u_2=-\dfrac{1}{x}$
  7. $y_p=-e^x\ln x+xe^x\cdot\left(-\dfrac{1}{x}\right)=-e^x\ln x-e^x$
  8. Since $-e^x$ is already in $y_c$ (absorbed into $C_1e^x$), write:
  9. General solution: $\boxed{y=(C_1+C_2x)e^x-e^x\ln x}$

7.5 Extension to Higher-Order ODEs

Variation of Parameters — $n$th Order

For $y^{(n)}+P_{n-1}y^{(n-1)}+\cdots+P_0y=R(x)$ with CF $y_c=\sum_{k=1}^nC_ky_k$, set $y_p=\sum_{k=1}^nu_ky_k$ and impose $n-1$ conditions:

$$\sum_{k=1}^nu_k'y_k^{(j)}=0, \quad j=0,1,\ldots,n-2$$ $$\sum_{k=1}^nu_k'y_k^{(n-1)}=R(x)$$

This $n\times n$ system (with coefficient matrix being the Wronskian matrix) is solved by Cramer's rule:

$$u_j'=\frac{W_j}{W}, \quad u_j=\int\frac{W_j}{W}\,dx$$

where $W_j$ is the Wronskian with the $j$th column replaced by $(0,0,\ldots,0,R)^T$.

Summary — Variation of Parameters

  • Always requires the CF (complementary function) to be known first
  • The Wronskian $W\neq0$ guarantees existence of the solution
  • Works for variable-coefficient ODEs if the CF solutions $y_1,y_2$ are known
  • Particular integral is $y_p=u_1y_1+u_2y_2$ where $u_1'=-y_2R/W$ and $u_2'=y_1R/W$
  • Always write the ODE in standard form (leading coefficient = 1) before applying the formulas
  • The method generalises systematically to any order $n$ via the Wronskian matrix
